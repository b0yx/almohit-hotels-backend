# Repository Cleanup Audit — Almohit Hotels

This audit classifies the files in the repository to determine what should be kept and what should be safely removed to achieve a clean production state.

## 1. Classification of Files

### 1.1 Must Never Be Deleted (Core Source Code)
* **app/**: Base PHP source code, controllers, models, middleware, support helpers, and custom authentication services.
* **routes/api.php**, **routes/web.php**, **routes/console.php**: Defined API and web endpoints.
* **database/migrations/**: Database schema definitions.
* **config/**: Application settings, including database connections, CORS, Sanctum, and Swagger.
* **artisan**: Laravel command line runner.

### 1.2 Safe To Keep (Project Metadata & Tooling)
* **composer.json** / **composer.lock**: PHP dependency manifests.
* **package.json**: Node tooling settings.
* **vite.config.js**: Vite asset compilation definitions.
* **phpunit.xml**: Testing configurations.
* **Procfile**: Railway startup release configurations.
* **railway.json**: Railway deployment specifications.
* **README.md**: Central documentation.
* **LICENSE**: Repository license (MIT).

### 1.4 Generated Files (Dynamically Created)
* **storage/api-docs/api-docs.json** and **api-docs.yaml** (Generated by Swagger scanning).
* **bootstrap/cache/*.php** (Cached configuration/routes).

### 1.5 Local Environment Files
* **.env**: Contains database keys and local API passwords (already correctly gitignored).
